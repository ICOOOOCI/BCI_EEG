# 按键大小、间距与观看距离

正常启动后，先显示无闪烁的静态预览，确认后才连接 EEG 并进入模式菜单。CMD 快速启动同样保留预览。只看布局可在本目录执行：

```powershell
python fbcca_keyboard_dual_mode.py --preview-layout
```

静态预览操作：

| 按键 | 操作 |
| --- | --- |
| ↑ / ↓ | 选择按键大小、间距、观看距离、屏幕对角线字段 |
| ← / → | 调整所选字段：像素每次 5 px、视角 0.1°、距离 1 cm、屏幕 0.1 英寸 |
| U | 切换像素 / 视角模式，两套尺寸分别保留 |
| Delete | 在屏幕尺寸字段清除对角线值 |
| Tab | 切换四角检查目标：1、0、SPACE（左下空白键）、句点 |
| 1 / 2 / 3 / 4 | 记录当前角落：容易找到 / 难找 / 需要转头 / 两者都有；然后移到下一个角落 |
| Enter | 接受当前有效布局并继续；未评价的角落记录为未检查 |
| Esc | 退出 |

观看距离是眼睛到屏幕的实际距离，需要自行量取并保持。屏幕尺寸填写**当前显示器有效显示区域的对角线英寸数**，不是分辨率或带边框尺寸。初始值为空；首次调整从 24 英寸开始编辑，这只是输入起点，不是自动检测结果。

像素模式直接设置绘制像素；距离只影响估算视角。视角模式需要先填写屏幕尺寸，并按 `物理边长 = 2 × 距离 × tan(视角 / 2)` 换算按键和间距。跨设备比较可使用相同视角参数，但应检查预览的实际值。估算假定正方形像素、眼睛位于屏幕中心正前方；所显示的按键视角是中心位置的等效值，四角另记录偏心角。这不是眼动或转头测量。

网格保留行列相同的边缘间距，剩余空间留在外围，不再分配到间距。默认 140 px 按键、30 px 间距；网格尽可能以屏幕中心为中心。放不下时按比例缩小，预览会显示 `FIT REDUCED` 和实际像素/视角；若要保持所设视角，应调整参数直到不再缩小。`Config.allow_layout_scaling=False` 时不自动缩小。

从中央 `+` 移向四角，按实际体验评价是否难找或需要明显转头。可以继续调整再检查；修改任何布局或距离参数都会清空旧评价。预览不判断某个角度是否“合适”，也不会将未检查的角落记为通过。

实验的会话 NPZ 中，`metadata_json` 保存：

- `config`：请求的单位、按键大小、间距、观看距离和屏幕尺寸。
- `display_info`：实际像素位置/大小/间距、适配比例、显示器像素尺寸、物理尺寸及四角估算偏心角。
- `display_info.static_preview`：预览确认状态、检查数量和每个角落的主观评价。

首个 EEG 试次暂存时，manifest 的 `context.layout_preview` 也保存预览快照，便于导出失败时恢复。沿用原有记录规则：未取得试次 EEG 时不创建实验记录；单独预览不保存会话。参数在本场会话生效，重启使用 `Config` 默认值。

无需 EEG 或显示窗口的自动检查：

```powershell
python -B -m unittest test_keyboard_layout -v
```
