# 模式二 EEG 实时分类：数据分析与优化报告

日期：2026-09-28。分析范围：用户指定的两份 session NPZ；“模式二”按 cued 提示测试解释。文件中的说明仅作为待核实的记录信息。

**结论：当前识别率偏低且跨场不稳定，最明确的采集异常是强 50 Hz 窄带干扰。一个小幅有效的离线候选已找到，但还不能声称系统已达到可靠实时输入水平。**

## 2. 信号与采集：主要问题在哪里

**50 Hz 附近占据接收端滤波前的大部分频谱能量。** 在保存的 uniform_data 上，以 Hann 周期图计算 49–51 Hz / 6–90 Hz 的功率比，每试次先取通道中位数、再取试次中位数，两场分别为 **99.2929% / 99.2973%**。这不是“99% 脑电丢失”或“信噪比只有 1%”，而是特定频带的相对能量比例。

独立审查的 source_data（插值之前、接收端滤波之前）也有约 **98.36% / 98.39%** 的占比，说明强窄带成分并非插值才产生。该独立统计使用对称 Hann 窗和全部 trial×channel 对的中位数，与上面的在线诊断一致口径略有不同，不能把小数差异解释为处理效果。

两场的工频比例几乎一样，且 640 个 trial×channel 对全部超过 50%，缺少干净对照，**不能说工频变大造成了第二场骤降**。这是需要优先排查的共同问题；具体是电极接触、参考/BIAS、外部耦合还是发布链路，现有数据不能唯一定位。

## 3. 时序与程序核验

- 修改前的源码哈希与两份记录一致。显式使用各场 metadata 参数重放，80 次的预测、分数、相关系数和权重全部一致，最大数值误差 **0.0**。
- 保存的 uniform_data 与 source_local_timestamps 插值重建结果完全相同；分析窗没有外推或再加一次 140 ms。所有窗都在刺激结束前完成。
- 保存窗内原始发布时间戳有 478 / 470 次非正间隔，兼容模式重建后为 0。重建窗内采样率约 249.78–250.24 Hz。没有设备样本计数器，仍无法确认少量丢样/重复；也没有物理延迟测量。
- 两场显示时序均无所定义的长/短帧异常，实际刷新率约 60 Hz。第二场启动测量约 59.885 Hz，帧表产生的等效刺激频率较参考约高 0.194%（15.8 Hz 约高 0.031 Hz）。这是小偏差，应改进刷新率校准，但现有证据不足以认定它是主要原因。
- 分类计算记录中位约 16 ms，每次完整选择约 5.28 s；当前速度主要受实验时序约束，优化几毫秒计算不是首要收益。
- 公共分类函数的历史默认值是 2 s / 5 谐波 / M3，与实时配置不同。离线复现必须传完整配置，不能只改窗长。

两场错误中分别有 20/27、26/36 个预测距离目标超过 1 Hz，因此也不能把问题只归为相邻 0.2 Hz 频率混淆。第二场 40 次中有 20 次预测到 <10 Hz，实际这种目标只有 10 次，显示低频偏置；是否由背景 alpha、噪声或注视状态导致，当前没有足够证据。


## 4. 实际做了哪些优化对照

固定 14 个候选；只按第一场正确数选择，并在评估第二场候选前冻结，平分时按预先排列次序。基线已知，且两场同人同日同顺序，第二场应称为“跨场核查”，**不是完全未触碰的独立验证集**。未丢弃试次、未减少 40 类候选、未使用 trial_id 或真标签作为解码输入。

| 候选 | 第 1 场：开发 | 第 2 场：跨场核查 |
|---|---:|---:|
| 原 FBCCA（基线） | 13/40（32.5%） | 4/40（10.0%） |
| 原第一子带 CCA | 6/40（15.0%） | 3/40（7.5%） |
| 后部 6 通道 | 11/40（27.5%） | 9/40（22.5%） |
| 枕部 3 通道 | 5/40（12.5%） | 4/40（10.0%） |
| 8 通道平均参考 CAR | 14/40（35.0%） | 5/40（12.5%） |
| CCA 正则化 0.01 | 9/40（22.5%） | 8/40（20.0%） |
| 仅基频，6–20 Hz | 2/40（5.0%） | 1/40（2.5%） |
| 2 谐波，上限 36 Hz | 6/40（15.0%） | 3/40（7.5%） |
| 线性去趋势 | 13/40（32.5%） | 4/40（10.0%） |
| **50 Hz 回归 + 原 FBCCA（冻结候选）** | 15/40（37.5%） | 6/40（15.0%） |
| 50 Hz 回归，取消陷波 | 13/40（32.5%） | 6/40（15.0%） |
| 50 Hz 回归 + 后部 6 通道 | 8/40（20.0%） | 7/40（17.5%） |
| 50 Hz 回归 + CAR | 13/40（32.5%） | 5/40（12.5%） |
| 50 Hz 回归 + 正则化 0.01 | 14/40（35.0%） | 6/40（15.0%） |

冻结候选是 **50 Hz 回归 + 原 FBCCA**：对每个通道在当前完整窗内联合拟合常数项、50 Hz 正弦/余弦，仅减去正弦/余弦分量；然后执行原有标准化、50 Hz 陷波、6–48 / 14–48 / 22–48 Hz 三子带和三谐波 CCA。保持 8 通道及原有权重、正则化。

该候选让两场各多对 2 个、没有把原来正确的改错：32.5%→37.5%，10%→15%；合计 21.25%→26.25%。各场配对精确 p=0.5，样本少且经过候选选择，**只是值得复测的小幅改善，不能宣称显著或稳定提升**。后 6 通道虽然在第二场达 22.5%，第一场却降到 27.5%，不能看完第二场后再把它当成获胜方案。

置信度阈值也不宜直接上线。例如相对分差 ≥0.1 时，第一场保留 9 次、正确 8 次（88.9%），第二场保留 14 次、只对 4 次（28.6%）；≥0.2 时第二场仍仅 1/4 正确。分数不是概率，现有数据也没有自由输入/空闲标签，无法标定空闲拒识。

## 5. 保留的主程序与使用方式

继续使用 `40-class classification/start_keyboard_dual_mode.cmd` 启动主程序 `fbcca_keyboard_dual_mode.py`。

50 Hz 回归优化已整合在主程序的 `Config.line_regression_hz` 参数中，默认 `None`（关闭）；需要复测该候选时，可将其设为 `50.0`。原有默认分类行为保持不变，预处理参数会写入新会话记录。

清理前已验证：默认配置的 80 个试次与原存储结果逐值一致；开启回归后的 80 个试次与冻结离线候选逐值一致，最大误差均为 0；参数检查及记录元数据往返验证通过。未进行新一轮真实采集，实际效果仍需新数据验证。

按用户要求，仅保留最终报告，辅助分析脚本、中间 JSON、单独图表和实验入口已移入回收站。原始 NPZ 保留在 `40-class classification/session_records/`，本报告保留主要结果、方法和原始数据哈希。

## 6. 下一次采集的优先顺序

1. **先修采集质量。** 对照实际接线逐一核验 P1/P2/PO3/POz/PO4/O1/Oz/O2，核对参考与 BIAS 接触、单位、LSL 输出类型与上游滤波。观察接收端滤波前频谱，做同条件短记录比较，确认 50 Hz 相对/绝对干扰明显下降。不要只靠显示端打开陷波就认定送入分类器的数据已变干净。OpenBCI 的显示滤波与网络输出应分别核对：[官方 GUI 控件说明](https://docs.openbci.com/Software/OpenBCISoftware/GUIWidgets/)。
2. **复测冻结算法。** 修正采集问题后，用新的随机顺序再采至少 3 个完整 block；保持同一目标集合、通道和时序，对相同新试次分别重放基线和冻结候选，报告每场结果、改善/恶化数。不要再用这 80 次反复挑最佳参数。
3. **单独验证窗长。** 建议采 5 s 完整分析窗的模式二数据，再在每个试次内比较 1.5 / 2 / 3 / 5 s，分别从原始窗裁剪后滤波，以避免短窗使用后续样本；同一试次的所有裁窗必须在同一个数据划分中。原程序已有 `paper_offline_5s` 预设。当前 NPZ 只有 1.5 s，不能靠补零、拼接其他试次证明更长窗有效。1/1.5≈0.667 Hz 是普通频谱栅格尺度，不能据此断言 CCA 无法区分 0.2 Hz。
4. **采集稳定后再做个体模板。** 建议总共采 5–6 个随机完整 block，并留至少 2 个后续 block 作固定验证；这是本项目的起步采集计划，非保证准确率的标准。每类仅两次目前不足以可靠训练/选择个体模板。TRCA 依赖试次之间可重复的任务相关成分，可参考[原作者实现](https://github.com/mnakanishi/TRCA-SSVEP)。

40 目标频率编码与 FBCCA 的基本方法参考 [Chen 等，2015](https://pubmed.ncbi.nlm.nih.gov/26035476/)。文献结果使用其自己的受试者、设备与协议，不能作为本次个人数据预期准确率。
